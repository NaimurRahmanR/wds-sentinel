# Bundled BattLeDIM data

This directory contains the BattLeDIM CSVs used by the reproducibility package. They are third-party research data, not original project material and not covered by the repository's MIT licence.

See:

- `../PROVENANCE.md` for source URLs, exact hashes and completeness;
- `../../THIRD_PARTY_DATA_NOTICE.md` for attribution and rights separation.

The files are read in place by the experiment scripts and are never modified by the pipeline.
